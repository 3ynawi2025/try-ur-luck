# تصميم إعادة الهوية البصرية — «Dark Luxe» (مواصفة)

**التاريخ:** 2026-08-22 — **الحالة:** معتمد من العميل (اختيار صريح + موافقة على التنفيذ)
**النطاق:** الواجهة والموشن فقط. **ممنوع** المساس بمنطق الألعاب أو عقد السوكت أو السيرفر.

## الفلسفة
الفخامة من التقيّد لا الإسراف. الذهب يُستخدم في ~5% من السطح فقط (الرصيد، CTA واحد، الفوز)، والباقي عمق ليلي محايد. مراجع: Ferrari (أكسنت واحد مقيّد + hairlines) وBugatti (تقشّف فاخر + مسافات تنفس).

## 2) الطباعة
- عربي: Cairo (نفس الأوزان، أحجام أكبر: display 40، h1 30، h2 24، h3 19، body 16).
- أرقام: Inter (tabular numbers).
- تسميات علوية (eyebrow): 11px، حروف متباعدة 1.4 (نمط Ferrari caption).
- **إزالة Playfair تمامًا** (7 مواضع تُستبدل بـ Cairo/Inter).

## 3) الأسطح والعمق
- زجاج حقيقي (expo-blur) للبطاقات العائمة + حدود شعرية.
- ظلان فقط: e1 (ناعم) و e2 (عميق)؛ توهج شامبين للعناصر الأساسية فقط.
- انحناءات موحدة: 4/8/12/20/28 + full.

## 4) الموشن (Jakub أولًا / Emil للتفاعلات المتكررة / Jhey للحظات الفرح)
- انتقالات شاشات: spring 250–400ms (damping 16–20).
- توزيع أوراق: stagger 120ms، ارتفاع 20px، تلاشي.
- عدّاد رصيد يتدحرج عند التغيير + نبضة 1.04 خفيفة.
- أزرار: scale 0.96 عند الضغط + haptic — بلا مبالغة.
- الفوز فقط: shimmer شامبين عابر (نادر = مسموح أن يُلاحظ).
- قواعد صارمة: transform/opacity فقط (60fps)، `prefers-reduced-motion` محترم، لا موشن للأزرار المتكررة، لا موشن يزيد عن 400ms في المسارات اليومية.

## 5) المكونات (إعادة بناء)
`Screen`، `GlassCard` (زجاج حقيقي)، `GoldButton` (يُعاد تصميمه كزر أساسي فاخر — الاسم يبقى للتوافق)، `Chip` (طبقات معدنية حقيقية)، `Avatar`، `Bits`، `Input`، `TabBar` (عائم زجاجي)، `FeltTable`، `PlayingCard` (أكبر وأوضح)، `InstructionsModal` (صفيحة زجاجية)، + **جديد:** `SoloGameScreen` غلاف مشترك + `useErrorToast` + `GameHeader` (يزيل ~50% تكرار شاشات اللعب).

## 6) الشاشات
- الصالة: بطل هادئ (اسم اللعبة ضخم + بطاقات ألعاب فخمة بمساحات تنفس).
- الطاولات: قائمة زجاجية مرتاحة.
- اللعب الخمس: جوخ أعمق، أوراق أوضح، صف إجراءات واحد مرتب.
- البروفايل/المتصدرين/الأصدقاء: نظام موحد هادئ.
- الترحيب/التسجيل: انطباع أول فاخر.

## 7) خطة التنفيذ (Approach A — تدريجي، معتمد)
1. theme.ts + الخطوط (إزالة Playfair مع إصلاح مواضعها فورًا).
2. المكونات الأساسية ثم مكونات اللعبة.
3. غلاف SoloGameScreen.
4. الشاشات: الصالة → الطاولات → الترحيب/التسجيل → الألعاب الخمس → البروفايل/المتصدرين/الأصدقاء.
5. مسح نهائي (موشن مخفض، lint، tsc، اختبارات).
